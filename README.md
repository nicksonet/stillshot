# Still Shot

WebXR-шутер для Meta Quest в духе SUPERHOT: время движется, только когда движешься ты.
Работает прямо в браузере шлема, без установки. На компьютере — с мышью и клавиатурой.

**Играть:** https://nicksonet.github.io/stillshot/ — открыть в браузере Quest и нажать ENTER VR.
Каждый пуш в `main` автоматически публикуется туда же (GitHub Actions → Pages).

## Локальный запуск

```
npm install
npm run dev
```

Vite поднимает HTTPS-сервер на порту 5173 (WebXR требует HTTPS) и печатает сетевые адреса.

**В шлеме:** Quest и компьютер в одной сети (например, раздача `nicksonet`) →
браузер Quest → `https://192.168.137.1:5173` → «Дополнительно» → «Перейти на сайт»
(сертификат самоподписанный) → **ENTER VR**.

## Управление

| | VR (Quest) | ПК |
|---|---|---|
| Стрелять | курок | ЛКМ |
| Бросить пистолет | кнопка хвата (с пистолетом в руке) | ПКМ |
| Подобрать пистолет | кнопка хвата рядом с пистолетом | E (или подойти вплотную) |
| Удар | резкое движение рукой в противника | F |
| Ходить | левый стик (или ногами) | WASD |
| Поворот | правый стик (по 30°) | мышь |
| Заново | курок после смерти | R / клик |

Правила: пуля — смерть. Убитые враги роняют пистолеты. Брошенный пистолет убивает.
Своей пулей можно сбить вражескую, пистолетом в руке — заблокировать.

## Разработка

- `npm run typecheck` — проверка типов
- `npm test` — Playwright: ПК-режим и VR через эмулятор Quest 3 (IWER), без шлема
- `https://localhost:5173/?emu` — эмулятор Quest 3 в обычном браузере на ПК, с панелью управления шлемом и контроллерами

Структура `src/`:

| Файл | Что делает |
|---|---|
| `game.ts` | игровой цикл, состояния, ввод VR/ПК, стрельба, столкновения |
| `time.ts` | масштаб времени от движения головы и рук |
| `enemy.ts` | враги: стрелки и рукопашники, ИИ, анимация |
| `levels.ts` | уровни: препятствия, точки появления, волны |
| `world.ts` | арена и коллизии со стенами |
| `bullets.ts`, `gun.ts`, `shards.ts` | пули, пистолеты, осколки |
| `audio.ts`, `text.ts` | процедурный звук, 3D-надписи |
| `emulator.ts` | эмулятор Quest (`?emu`) |

`window.__game` — отладочный API для тестов (состояние, прицеливание, выстрел, замедление времени).
